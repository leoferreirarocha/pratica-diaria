# Pratica diaria em cinco linguagens

Pequenos exemplos de Python, C, Java, C++ e C#.

Este repositorio recebe **25 commits automatizados por dia**, cinco por linguagem.
Cada commit troca uma linha de entrada em um exemplo: quadrado, paridade,
numero triangular, ultimo digito ou dobro. O historico representa a execucao
da automacao; nao representa 25 tarefas manuais de desenvolvimento.

As entradas ficam entre 1 e 997, e cada arquivo funciona de forma independente.
Execute Python com `python python/square.py`; C com
`gcc c/square.c -o square`; C++ com `g++ cpp/square.cpp -o square`;
Java com `javac java/Square.java` e `java -cp java Square`.
Os exemplos C# podem ser compilados individualmente em um projeto console .NET.

O agendamento local e os logs ficam fora do controle de versao.
Nao sao criados commits vazios nem alteradas datas do historico.
